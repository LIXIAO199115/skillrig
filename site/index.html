02 / Inspection ledger

Every install
leaves a receipt.

A marketplace gives you a name and a description. SkillRig gives you provenance, a hash, a scan, and a way to notice when something changed after the fact.

  1. 01

    Signature before parsing

    The Ed25519 signature over the index is checked before a single entry is read. A modified catalogue fails closed.

  2. 02

    A hash for every file

    Paths and contents are hashed together. References and scripts are covered, not just SKILL.md.

  3. 03

    22 rules, five severities

    Remote execution, credential reads, exfiltration, persistence, prompt injection, hidden Unicode, tool overreach.

  4. 04

    Drift you can see

    Project and global lockfiles record every file hash. list, doctor, and audit report what changed.

03 / Packs

Useful together.

A pack is a named group, not a bundle of copies. Every member is resolved, scanned, and hashed on its own, so one bad entry cannot hide behind four good ones.
